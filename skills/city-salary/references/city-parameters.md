## 城市参数结构（扩展全国地市的方法）

模板中有两个工厂函数（见 `assets/calculator.html`），**新增城市只需添加一行**：

**`CI()` —— 广东型**：五险基数各自独立（养老全省统一 **5521~27603**，粤人社发〔2026〕24号：下限片区废止与下限统一 5510 自 2026-01-01 起、机关事业单位自 2026-01-01 起即为 27603/5521、企业职工自 2026-07-01 起为 27603/5521，该文只管养老、不含医保；失业为**法定市级口径**，《广东省失业保险条例》第八条——下限＝本市现行最低工资标准、上限＝本市上年度城镇非私营单位在岗职工月均×3，工厂默认 `unemp:{min:2040,max:hf.max}`，一/二类市与已取证市在 opt 中逐市覆盖；工伤法定无缴费基数上下限（**第八十一批起 `inj` 改 `{min:0,max:0}`＝不夹取**，普通职工按「单位职工工资总额×费率」计缴；上下限仅针对八类「特定人员单项工伤保险」＝全省全口径月均×300%/×60%，逐年 2023年度 5284~26421、2024年度 5500~27501、2025年度 5510~27549、2026年度 **5521~27603**（韶人社函〔2026〕44号），第八十四批起写入 `injSpecial:{min,max,from,to,src}`；第八十四批市级实证：佛山/东莞通告逐字「不设上下限」、惠州逐字「企业职工工伤保险缴费基数不设上、下限」，省级依据粤人社发〔2023〕22号只管「特定人员单项工伤保险」，人社部发〔2019〕34号实为《职业技能等级证书监督管理办法（试行）》、与工伤无关））

```js
CITIES.城市key = CI("城市名",
  {min:医保基数下限, max:医保基数上限, comp:医保单位费率, emp:医保个人费率},
  生育参数(可null, 默认并入医保单位费率),
  {min:公积金基数下限, max:公积金基数上限},
  养老基数下限(默认4775),
  可选标记 {hukou:true, tier2:true, ltc:true, tiers:[...], note:"数据说明"}
);
```

**`CIU()` —— 统一基数区间型**：五险共用一个基数区间（北京/上海、四川 21 市州等），各险费率与公积金区间按当地政策传入；医保基数不随统一区间的市可用 `opt.med` 单独覆盖

```js
CITIES.城市key = CIU("城市名",
  {min:五险统一基数下限, max:五险统一基数上限},
  {medComp:医保单位费率, medEmp:医保个人费率,
   unempComp:失业单位费率, unempEmp:失业个人费率,
   injComp:工伤费率, hfRateMax:公积金比例上限, medFixEmp:医保个人每月固定额},
  {min:公积金基数下限, max:公积金基数上限},
  可选标记 {region, dataYear, rent, note:"数据说明", warn:true, med:{min,max,comp,emp}}
);
```

`opt` 会被浅合并到城市对象上，用于覆盖任意字段。城市字段说明：

| 字段 | 含义 |
|------|------|
| `region` / `dataYear` | 数据依据的地区与年度，显示在页脚 |
| `hukou` | 户籍切换（仅深圳有） |
| `tiers` | 医保多档（深圳二档、东莞三档、潮州三档等） |
| `ltc` | 长护险开关（深圳 0.125%、珠海/东莞/清远 0.15%） |
| `hfRateMax` | 公积金比例上限：广东 12、四川 12、上海 **7** |
| `medFixEmp` | 医保个人每月固定附加额：北京大额医疗互助 **3 元/月** |
| `rent` | 住房租金专项附加扣除档位（个税） |
| `note` | 政策说明文字，显示在页脚 |
| `warn` | 数据待确认标记，显示为橙框 |

> 改造要点：非广东城市加入时，务必用 `CIU()` 或显式覆盖 `pension.max`/`unemp`/`inj`——`CI()` 的养老上限与失业/工伤区间是**广东省级标准**，直接套到外省会算错。

数据状态说明：**茂名**公积金基数为 2025 年度（2026 年度通知已发布但未见具体数字，橙框"数据待确认"）；**汕尾**单建统筹总费率 4.8% 官方已确认（待遇清单 2026 年版），但未拆分个人比例，按个人 0 计；其余城市均为官方文件数据。揭阳数据来源：基数（揭医保〔2025〕67号，2026年度 3727~18636）、费率（揭府规〔2022〕6号，单位6%/个人2%）。
