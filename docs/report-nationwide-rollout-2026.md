## 三、全国政策口径差异图谱（本项目的核心知识产出）

### 3.1 缴费基数的六种组织方式

| 类型 | 代表地区 | 说明 |
|---|---|---|
| 全省/全区统一 | 大多数省份 | 省级统筹，全省一个上下限（内蒙古、青海、海南、宁夏、西藏、新疆等） |
| 省内分档 | **湖北** | 按地区分 3 档（4,498 / 4,299 / 4,254 下限） |
| 医保基数独立 80%~300% | **内蒙古、贵州** | 养老等为 60%~300%，医保下限取 80%，上限同为 300% |
| 医保基数不设上限 | **新疆** | 下线同养老，高于下限即按实际申报工资核定 |
| 医保基数按市单独确定 | **江西**（设区市）、**陕西** | 各市自行确定医保基数 |
| 养老与医保双口径 | **福建** | 养老 4,043~22,607；医保/工伤 4,579~22,893 |

此外内蒙古的医保基数按**业务年度（7 月 1 日—次年 6 月 30 日）**单独确定，与养老的自然年口径并不同步。

### 3.2 费率的极值分布

| 险种 | 范围 | 极值 |
|---|---|---|
| 工伤（一类行业基准） | 0.1% ~ 0.4% | **最低：西藏 0.1%**；海南 0.15%；山西 0.23%；**最高：贵州 0.4%** |
| 医保（单位，含生育） | 6% ~ 9.8% | **最高：乌鲁木齐 9.8%**；广州/深圳约 6.5% 级 |
| 失业 | 多为 0.5%/0.5% | **特殊：甘肃 0.7%/0.3%**（单位高于个人） |
| 公积金（比例上限） | 5% ~ 12% | **特殊：上海 7%**（其余均 12%） |

### 3.3 大额医疗补助的三种形态

这一项对「个人到手」影响直接，且全国做法差异极大：

| 形态 | 代表 | 个人负担 |
|---|---|---|
| 固定额（元/月） | 北京 3、重庆 5、酒泉 5、和田 10、青海全省 10、宁夏（银川等）13、徐州 11.83、芜湖 40 | 按固定额直接扣 |
| 比例制 | 兰州（全口径 0.5%，单位个人各半）、乌鲁木齐（个人 0.5%）、吐鲁番（各 0.25%） | 随基数浮动 |
| 财政/基金承担 | **西藏**（自治区财政专项）、**海南**（从统筹基金列支） | **个人不缴** |

### 3.4 住房租金专项附加扣除档位（依据国发〔2018〕41号第十七条）

| 档位 | 数量（座） | 构成 |
|---|---|---|
| **1,500 元/月** | 36 | 4 直辖市 + 27 省会/首府 + 5 计划单列市（大连/青岛/宁波/厦门/深圳） |
| **1,100 元/月** | 127 | 市辖区户籍人口 > 100 万 |
| **800 元/月** | 174 | 市辖区户籍人口 ≤ 100 万，以及全部地区/自治州/盟（无市辖区） |

> **档位经两轮核查修正**：第 1 波补深时修正了豫鄂湘皖闽赣六省（此前非省会城市一律按 1,100 暂估）；2026-09-26 又对第 0 波与重庆/山东/辽宁/吉林/黑龙江批次的 8 省市逐市复核，**共修正 39 市**（详见第五节第 6 项）。

**五个「零 1,100」的省级区域**：新疆（13 地州全部 800）、青海（7 市州全部 800）、西藏（6 市地全部 800）、宁夏（4 市全部 800）、吉林（8 市州全部 800）——这些省区除首府外无城市市辖区户籍人口超过 100 万。

**一处口径争议**：海南儋州（户籍 109.55 万 > 100 万，但为**不设区的直筒子市**，「市辖区户籍人口」口径是否等同全市存在争议），已按 1,100 写入并标 `warn`，建议以主管税务机关认定为准。

### 3.5 公积金上限的三种确定规则

| 规则 | 代表 | 说明 |
|---|---|---|
| 省级统一公布数值 | 山东、宁夏、甘肃（省级单位） | 一次发布，全省可用 |
| 各市自行公布 | 多数省份 | 逐市发文，需逐市取数 |
| **只公布规则、不公布数值** | **内蒙古锡林郭勒盟/阿拉善盟、西藏日喀则/那曲/阿里** | 仅给「上限 = 上年度城镇非私营月均工资 × 3」，需代理值 + `warn` |

### 4.3 数据可信度分层

每波都标注了查不到的项目，**共 171 座城市带 `warn`（占 50.7%）**，原因是「官方尚未发布或未拆分」，而非调研不到位：

| 缺口类型 | 说明 | 处理方式 |
|---|---|---|
| 省级年度基数未发布 | 河南/福建/江西 2026 年度未出；海南 2026 年度未公布 | 沿用上一年度 + `warn` + `note` 写明 |
| 市级医保费率未公开 | 河北 5 市、山西 5 市、内蒙古兴安盟、新疆 3 地州等 | 按省级区间估算 + `warn` |
| 公积金沿用旧年度/按规则估算 | 甘肃嘉峪关、内蒙古 3 盟、青海海北/玉树、西藏 3 市地 | 显式代理值 + `warn` |
| 大额/大病金额未拆分或未公开 | 内蒙古部分盟市、甘肃多数市州 | 按全额或 0 计入 + `note` 说明 |
| 租金档位存疑 | 湖南衡阳（推断）、海南儋州（口径争议） | 按推断写入 + 建议以主管税务机关认定为准 |

**原则：查不到就标 `warn` 并写明，绝不编造；不因个别缺口阻塞整批推进。**

## 七、经验沉淀

### 7.1 可复用的每省 SOP（8 步）

1. **省级调研**：拿到省级基数上下限 + 文号（多数险种省级统一，一次覆盖全省）
2. **并行市级调研**：逐市取医保单位费率、公积金基数上下限 + 文号、大额金额、租金档位、最低工资档位归属
3. **落盘来源文档** `docs/policy-<省>-<年>.md`：数值 + 文号 + 缺口清单
4. **写 CITIES**：统一走 `CIU()` 工厂 + `opt` 浅覆盖（计算逻辑零改动）
5. **文档涟漪**：`AGENTS.md`（省级参数条目）/ `SKILL.md`（省级参数段 + 城市表行）/ `README.md`（城市清单 + 数据说明）
6. **补测试**：城市总数 + 每省 ≥3 条参数抽查 + key 防覆盖断言
7. **五命令验证**：`sync → test-calc → check-dom → check-sync → test-export`
8. **交付**：commit + push + 线上核验

### 7.2 四条关键教训

1. **守卫必须自校验**。新加的重复 key 守卫第一版就漏扫了 21 个城市却报「通过」——**检查器的覆盖面本身要能被验证**，否则缺失的检查比没有检查更危险。
2. **`SearchReplace` 改同名文本行前先 grep 确认唯一性**。吉林省与湖南省的租金行文本完全相同，导致两次改错位置。
3. **文档里不要写会持续变化的数字**。「实现状态」行原本每波都要改城市总数，改为「指向计划文档」后涟漪从 5 处降到 2 处。
4. **官方「只给规则不给数值」时，用同省同规则的已知值作显式代理**，并标 `warn` + `note` 写明「待核实」——既不编造，也不阻塞城市可用性。

### 7.3 统计口径的一处副产品

`rent:` 字面量在源码中只出现 321 次，但解析后有 337 座城市——原因是 `CI()` 工厂内置 `rent:1100`、`CIU()` 内置 `rent:1500`，**等于该默认档的城市不写字面量**（广东 15 座 + 成都 1 座）。这不是数据缺失，但在做「源码字面量计数」类校验时需注意**工厂默认值也是数据来源**。

## 八、结论

1. **目标达成**：337 座城市 100% 覆盖，28 个省份分组，5 个批次交付，全部经五命令验证 + 线上逐字节核验。
2. **知识产出**：除代码与数据外，沉淀了 7 份**带文号的来源文档**与 1 份排期计划，把「全国社保公积金口径差异」（6 种基数组织方式、3 种大额补助形态、3 种公积金规则、租金 3 档分布）显式记录下来，可追溯、可复核。
3. **质量体系**：5 项守卫 + 5 命令链，且守卫本身经过自校验；过程中累计拦下 7 处陈旧表述、4 次城市丢失（2 次 key 冲突）、5 类数据错误（含公积金上限 2 处、租金档位 1 类）。
4. **诚实标注**：171 座城市带 `warn` 并写明缺口原因与暂用值，无一处编造；缺口清单按省落盘，供年度检查点复核查。
