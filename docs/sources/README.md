| 类型 | 案例 | 特征 |
|------|------|------|

### 一条方法论

「有官方来源」≠「可以改数据」。复核时要同时过四关：
**① 口径对不对（企业 vs 机关事业）→ ② 生效了没有 → ③ 数字有没有歧义 → ④ 来源是不是官方**。
四关全过才改；缺任何一关就只记录、不改值。

## ⚠️ 一次重大的诊断修正：DNS 劫持 + 域名猜测错误

> 2026-10-02，用户关闭代理后重测，**结果完全不变**。深挖后发现两个此前被忽略的原因。

### 原因一：本地 DNS 是「通配解析器」，把所有域名都指向路由器

```
nslookup gjj.beihai.gov.cn      → 192.168.68.1   （路由器）
nslookup www.beihai.gov.cn      → 192.168.68.1   （同样是路由器，但该域名真实存在！）
nslookup zjt.gxzf.gov.cn        → 192.168.68.1   （同上）
```

**所有域名——包括不存在的——都解析到 `192.168.68.1`。**
这说明本地 DNS（DHCP 下发的 192.168.68.1）**对任何查询都返回路由器地址**，
**把真实存在的域名也解析坏了**。

**用 DoH（DNS over HTTPS，`https://223.5.5.5/resolve`）绕过本地 DNS 后，真相才显现**：

| 域名 | DoH 真实结果 |
|------|-------------|
| `www.beihai.gov.cn` | **202.103.252.132** ✓ 存在 |
| `zjt.gxzf.gov.cn` | **202.103.252.132** ✓ 存在 |
| `gjj.lanzhou.gov.cn` | **61.178.48.89** ✓ 存在 |
| `gxwzgjj.gov.cn` | **121.31.79.141** ✓ 存在 |
| `www.whsgjj.com` | **58.18.64.14** ✓ 存在 |

**验证**：用 `curl --resolve <域名>:80:<真实IP>` 绕过本地 DNS 后，
`gjj.lanzhou.gov.cn` 与 `www.beihai.gov.cn` **均返回 HTTP 200** ✓。

| 此前的结论 | 修正后 |
|-----------|--------|
| 「惠州/汕头/肇庆/汕尾/海口/三亚/乌鲁木齐的公积金站点不可达」 | **应改为：我猜的域名不存在，真实官网地址尚未查到** |

### 方法论教训

1. **不要把「猜的 URL 返回 000」当作「站点不可达」** ——
   必须先用 DNS 区分「域名不存在（NXDOMAIN）」与「域名存在但连不上」
2. **本地 DNS 不可信时要换 DoH** —— 一个通配解析器会让所有诊断失真
3. **`curl --resolve` 是绕过坏 DNS 的可靠手段**（DoH 查真实 IP → `--resolve` 直连）
4. **域名要靠检索获得，不要靠命名模式推断** —— 本仓库大量城市的公积金中心
   使用独立域名（`gxwzgjj.gov.cn`、`whsgjj.com`、`cxzfgjj.com`、`njsgjj.cn` 等），
   并不遵循 `gjj.<城市>.gov.cn`

### 后续可行路径（已修正）

1. **先 DoH 查真实域名是否存在**，再决定是否抓取
2. **用检索找真实官网**（而非猜测域名）
3. 抓取时用 `--resolve` 绕过本地 DNS
4. 若确需修 DNS：把网卡 DNS 改为公共 DNS（如 223.5.5.5），或关闭路由器的 DNS 劫持
### DNS 修复后的第三轮尝试（2026-10-02）

用户把网卡 DNS 改为公共 DNS 后，**真实域名全部恢复可达** ✓：

```
curl http://www.beihai.gov.cn/   → 200
curl http://gjj.lanzhou.gov.cn/  → 200
curl http://zjt.gxzf.gov.cn/     → 200
```

**这证实了「原因一（DNS 劫持）」的判断** —— 此前对真实域名的 000 确实是 DNS 造成的。

### 但 NXDOMAIN 的域名不会因为 DNS 修复而出现

**关键区分**：

| 情况 | DNS 修复后 |
|------|-----------|
| 域名**存在**、此前因 DNS 劫持返回 000 | **恢复可达** ✓ |
| 域名**不存在**（NXDOMAIN，我猜错的） | **仍然不可达** ✗ —— 必须换真实域名 |

因此第三轮的重点转为：**用检索找真实官网，而不是继续探测猜测的域名**。

## 第九轮（2026-10-10）—— Windows OCR 打通扫描件死路，五城公积金定案

### 本轮最重要的方法论突破：扫描件/PDF 不再是死路

前三轮把「官方正文是扫描图片 / 无文字层 PDF」一律记成 `official-partial`，等于放弃了整批城市的官方来源。实际上本机有可用的 OCR 链路，四步：

1. **取内嵌图**（唯一可行栅格化手段）：
   ```python
   from pypdf import PdfReader
   for im in PdfReader(path).pages[i].images: open(f'p{i}.jpg','wb').write(im.data)
   ```
   本环境 **无 fitz / pdf2image / pypdfium2 / pytesseract**，pypdf 是唯一解；`python` 命令是坏的，必须用绝对路径
   `C:\Users\weant\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`（设 `$env:PYTHONIOENCODING='utf-8'`）。
2. **旋转 270°**（`cs-rot.ps1 -Deg 270`）：政府扫描件多为横排 3507×2480，不旋转 OCR 全是乱码。**270° 是对的，90° 出乱码**。
3. **二值化 + 放大**（`cs-bin.ps1 -Scale 2 -Thresh 175`，`LockBits` + Marshal 逐像素）：用于浅色/泛黄扫描件。
4. **OCR**：`powershell.exe -NoProfile -File cs-ocr.ps1 -PathList "a.jpg;b.jpg"`
   —— **必须用 Windows PowerShell 5.1（`powershell.exe`），不能用 pwsh 7**；pwsh 报「找不到类型 [Windows.Media.Ocr.OcrEngine]」。
   `Add-Type -AssemblyName System.Runtime.WindowsRuntime` + `[Windows.Media.Ocr.OcrEngine,Windows.Foundation,ContentType=WindowsRuntime]`，
   语言 `New-Object Windows.Globalization.Language 'zh-Hans-CN'`，**图片高 >1400px 必须按 1400px 切片**，否则识别率骤降。

OCR 输出有噪声（「公积金」常被读成「公私金」「公稆金」），**必须算式自校验**，不能直接采信。

### 两条关键教训

**① 反推方向会骗过算式自校验。** 鹰潭仓库原值 `hf 2100~24866.67` 是上一轮「从月缴存额反算」得来的
（5968÷24%=24866.67、210÷10%=2100），当时**算式自校验完美通过**，但方向是反的：
官方先独立确定缴存基数（24863 = 8287.67×3、2090 = 最低工资），再对「基数×比例」四舍五入得到月缴存额。
本轮读到官方原文才发现差 3.67 元（上限）和 10 元（下限）。
→ **算式自校验只在「官方值 = 由官方另两个值算出」时有效；如果某个值本身就是从目标值反推的，自校验必然通过，等于没校验。**

**② 域名猜错就下「not-found」是过早结论。** 随州此前只试了 `zfgjj.suizhou.gov.cn` 与 `gjj.suizhou.gov.cn` 两个 NXDOMAIN 就记 not-found，

3. **政府门户站内搜索基本不可用**：德阳走 `www.sczwfw.gov.cn/jsearchfront/search.do`（结果 JS 渲染）、广安是 POST 表单、资阳 `/search5/html/searchResult.html` 同样 JS 驱动。curl 只能拿到壳，**不要在这些站内搜索上浪费轮次**。
4. **`.ps1` 文件里不要写中文字面量**：`powershell.exe -File` 按 ANSI 读取 UTF-8 无 BOM 文件，中文会把引号/正则打乱（报 `Missing ')' in function parameter list`）。含中文的抓取逻辑要内联到 `pwsh -Command`，或脚本里只用 ASCII（如 `[\u516c\u79ef\u91d1]`）。
5. **通过 `-File` 传数组参数会退化成单个字符串**：`cs-find.ps1 -Query "A" "B"` 静默失效，改用逗号分隔字符串再 `-split ','`。
6. **DoH `Status: 0` 但无 `data` 字段 = NODATA**（域存在但无 A 记录），与 `Status: 3`（NXDOMAIN）要分开判断，前者同样不可用。
7. **同站不同子域可能有访问控制差异**：资阳 `/content/<id>.html` 在 `www.sczygjj.cn` 下直连一律 `code=000`（http/https 均然），换裸域 `http://sczygjj.cn/content/<id>.html` 立刻 200。遇到 000 不要立刻判定「站点不可达」，先把 www 去掉再试。
