| 类型 | 案例 | 特征 |
|------|------|------|
| **① 口径误判** | 广西报 6.4%、山东报 7.3% | 把**机关事业单位**费率当企业费率；**报出的值比仓库低 0.6~0.7pp** |

### 一条方法论

「有官方来源」≠「可以改数据」。复核时要同时过四关：
**① 口径对不对（企业 vs 机关事业）→ ② 生效了没有 → ③ 数字有没有歧义 → ④ 来源是不是官方**。
四关全过才改；缺任何一关就只记录、不改值。

## ⚠️ 一次重大的诊断修正：DNS 劫持 + 域名猜测错误

> 2026-10-02，用户关闭代理后重测，**结果完全不变**。深挖后发现两个此前被忽略的原因。

### 原因一：本地 DNS 是「通配解析器」，把所有域名都指向路由器

```
nslookup gjj.beihai.gov.cn      → 192.168.68.1   （路由器）
nslookup www.beihai.gov.cn      → 192.168.68.1   （同样是路由器，但该域名真实存在！）
nslookup zjt.gxzf.gov.cn        → 192.168.68.1   （同上）
```

**所有域名——包括不存在的——都解析到 `192.168.68.1`。**
这说明本地 DNS（DHCP 下发的 192.168.68.1）**对任何查询都返回路由器地址**，
**把真实存在的域名也解析坏了**。

**用 DoH（DNS over HTTPS，`https://223.5.5.5/resolve`）绕过本地 DNS 后，真相才显现**：

| 域名 | DoH 真实结果 |
|------|-------------|
| `www.beihai.gov.cn` | **202.103.252.132** ✓ 存在 |
| `zjt.gxzf.gov.cn` | **202.103.252.132** ✓ 存在 |
| `gjj.lanzhou.gov.cn` | **61.178.48.89** ✓ 存在 |
| `gxwzgjj.gov.cn` | **121.31.79.141** ✓ 存在 |
| `www.whsgjj.com` | **58.18.64.14** ✓ 存在 |

**验证**：用 `curl --resolve <域名>:80:<真实IP>` 绕过本地 DNS 后，
`gjj.lanzhou.gov.cn` 与 `www.beihai.gov.cn` **均返回 HTTP 200** ✓。

### 方法论教训

1. **不要把「猜的 URL 返回 000」当作「站点不可达」** ——
   必须先用 DNS 区分「域名不存在（NXDOMAIN）」与「域名存在但连不上」
2. **本地 DNS 不可信时要换 DoH** —— 一个通配解析器会让所有诊断失真
3. **`curl --resolve` 是绕过坏 DNS 的可靠手段**（DoH 查真实 IP → `--resolve` 直连）
4. **域名要靠检索获得，不要靠命名模式推断** —— 本仓库大量城市的公积金中心
   使用独立域名（`gxwzgjj.gov.cn`、`whsgjj.com`、`cxzfgjj.com`、`njsgjj.cn` 等），
   并不遵循 `gjj.<城市>.gov.cn`

### 后续可行路径（已修正）

1. **先 DoH 查真实域名是否存在**，再决定是否抓取
2. **用检索找真实官网**（而非猜测域名）
3. 抓取时用 `--resolve` 绕过本地 DNS
4. 若确需修 DNS：把网卡 DNS 改为公共 DNS（如 223.5.5.5），或关闭路由器的 DNS 劫持

## 一次崩溃验证了「边查边写」的价值

2026-10-01 会话中途 **DSH 崩溃**。但因为第二轮已改为

## 技术要点（复用）

1. **知识库是 SPA**，`--dump-dom` 需 `--virtual-time-budget=22000` 起，20 秒内常拿不全，可重试。
2. **PDF 用 `python` + `pypdf`**（已装）；**DOCX 用 python `zipfile` 读 `word/document.xml`**。
   Jina 抓 PDF 常失败（如河南那份只回 799 字符，下载后用 pypdf 拿到 2558 字符正文）。
3. **知识库条目的「答复依据」是折叠面板**，内容不在初始 DOM 里，`--dump-dom` 拿不到。
4. **大规模 fan-out 的结果要写文件**，不要靠返回值传回 —— 返回值有长度上限，
   上一轮 9 个 Agent 的结果只回来了 7/28 个省。
5. **子 Agent 会在仓库根目录留临时文件** —— 抓取产物请写系统临时目录。
