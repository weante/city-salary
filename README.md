# city-salary · 城市工资计算器（Agent Skill）

[![CI](https://github.com/weante/city-salary/actions/workflows/ci.yml/badge.svg)](https://github.com/weante/city-salary/actions/workflows/ci.yml)
[![在线使用](https://img.shields.io/badge/%E5%9C%A8%E7%BA%BF%E4%BD%BF%E7%94%A8-city--salary.pages.dev-F38020?logo=cloudflare&logoColor=white)](https://city-salary.pages.dev/)

一个开箱即用的**按城市计算工资**的 Agent Skill：社保、公积金、个人所得税、年终奖、历史明细与趋势图，打开先选城市，按当地政策实时计算。**已内置 337 城，全国地级及以上城市 100% 覆盖**（28 个省区市：京沪渝津 + 粤川鲁辽吉黑苏浙豫鄂湘皖闽赣冀晋陕桂云贵甘宁蒙新青琼藏；民政部 2024 年底口径共 337 个地级及以上城市）。

同时兼容多种 Agent 工具（Claude Code / Codex / opencode / TRAE / WorkBuddy 等），既可作为 **Agent Skills（SKILL.md）** 安装，也可作为项目指令（**AGENTS.md**）使用。

## 在线使用

**<https://city-salary.pages.dev/>**

由 **Cloudflare Pages** 托管，推送 `main` 后自动部署 `site/` 目录，打开即用、无需安装。适合想立刻算一次、或在不方便装 Agent 的环境里使用。

计算器是**单文件 HTML、零依赖**，所以也可以直接下载 [`site/index.html`](site/index.html) 双击打开——与在线版**功能完全一致且离线可用**。在线版与仓库内文件在每次部署后逐字节一致（换行规范化后比对）。

- **单月计算**：税前工资 → 五险（养老/医疗/失业/生育/工伤，基数各自独立可调）→ 公积金（0 或 5%~当地上限）→ 个税（累计预扣预缴）→ 到手现金；支持七项专项附加扣除（勾选启用、强制上限、互斥二选一）、税优健康险/个人养老金/企业年金年度抵扣
- **年终奖**：单独计税 + 六个临界值陷阱速查（36000/144000/300000/420000/660000/960000），命中自动警告
- **历史明细**：逐月可调工资与基数，按累计预扣计算每月个税；当前月后自动生成预测月份（虚线显示）；累计汇总 + 可筛选系列的趋势图（SVG 折线、双侧坐标轴、悬停高亮）；一键导出 PDF
- **数据时效**：内置核查机制，**每年 1 月核查医保费率、7 月核查养老/公积金基数，限期费率文件（如上海医保 9%）按其到期日单独触发**——不同险种调整周期不同、阶段性政策到期即可能变化，分三类检查点

## 口径说明（影响"到手多少钱"的四条关键约定）

> **完整的计算规则定义（公式、常量、全部口径选择）见 [docs/calculation-spec.md](docs/calculation-spec.md)（计算口径白皮书）**。
> 那份文档的每个常量都由 `check-sync` 的检查 I 与实现比对，改了代码不改它会 CI 变红。
> 下面四条是最容易踩的要点。

1. **大病医疗只在年度汇算清缴时扣除**，不进月度预扣预缴——模板中该项只影响"年度预估"，不影响当月税额；且年度金额**按全年 12 个月计并封顶 80000 元**，不随就业月数折算
2. **两个"年度个税"口径不同**：单月页"年度预估"是汇算后口径（含大病医疗），历史页"累计个税"是月度预扣口径（不含）——两者差额≈大病医疗扣除效果，不应相等
3. **补充扣除既减税也从实发中扣现金**：个人养老金、企业年金个人缴费、税优健康险都是个人真实支出，工资条中列为扣款项，最后一行是"到手现金"而非"实发工资"
4. **企业年金个人缴费**按"本人缴费工资计税基数"计算（模板以养老缴费基数作为该基数），不是按税前月薪的 4%

## 维护与测试

```bash
npm test                    # ★ 一次跑完下面五项（零依赖，无需 npm install）
node tools/test-calc.js     # 计算回归（改参数/改逻辑后必跑）
node tools/check-golden.js  # 黄金用例：整块渲染输出的逐字节比对
node tools/check-dom.js     # 单文件 HTML 的静态结构检查
node tools/check-sync.js    # 漂移检查 A–I：镜像 / 城市参数锚定 / 陈旧表述 / 断言数 / 年度口径 / 数据状态表 / 限期费率 / warn 清单 / 计算口径
node tools/test-export.js   # 导出 PDF 降级链
node tools/ci-selfcheck.js  # 零依赖红线自检（CI 也会跑）
node tools/sync.js          # 同步源文件到镜像位置

npm run golden:update       # 渲染输出有意变更后，重新冻结黄金快照
npm run warn:update         # warn 集合变化后，重新生成缺口清单
```

**数据运营**：核查节奏与 SOP 见 [docs/maintenance-calendar.md](docs/maintenance-calendar.md)；172 个 warn 城市的缺口分层与补齐动作见 [docs/warn-backlog.md](docs/warn-backlog.md)。限期费率（到期即可能恢复原费率的阶段性政策）由 [tools/policy-expiry.js](tools/policy-expiry.js) 登记，**已到期而未记录处置的条目会让 CI 变红**，强制联网核查。

**黄金用例是什么**：`test-calc.js` 断言的是**具体数值**（8980 项断言），覆盖已知关注点；`check-golden.js` 捕获的是**整块渲染结果**（16 个用例覆盖结构差异：直辖市/省统一/多档医保/户籍区分/长护险/市级基数覆盖/跨年度/极端基数，输入变体覆盖触底与封顶夹取、公积金不缴、起始月晚于当前月、全部扣除、年终奖陷阱），覆盖所有没被单独断言到的字段。前者告诉你"哪个数错了"，后者告诉你"有什么变了"。改动渲染输出后跑 `npm run golden:update` 重新冻结。

**CI 门禁**：`.github/workflows/ci.yml` 在 push / PR 时按 Node 18/20/22 三个版本跑完整守卫链。注意 CI 里**刻意不跑 `sync.js`**——sync 会把镜像"修好"，反而掩盖"改了源文件忘了同步"的漂移；镜像一致性由 `check-sync` 的 A 检查做逐字节比对。

全部为零依赖 Node 脚本，无需 `npm install`，`tools/ci-selfcheck.js` 会守住这条红线（禁止声明依赖、禁止在 scripts 里调用包管理器、禁止 `tools/` 下 require 第三方包）。测试的做法是**从 `calculator.html` 里抽取真实的 `<script>` 放到最小 DOM 桩上执行**——测的是真正会跑在用户浏览器里的那份代码，而不是测试文件里重写一遍的副本。

## 使用示例

对话中直接说：

- “我月薪 7500，深圳，社保公积金基数 6750，公积金 5%，非独生赡养老人，到手多少？”
- “月薪 3 万在北京，公积金按 12% 缴，到手多少？”
- “上海月薪 2 万，公积金 7%，还要扣个人养老金 1000，实际到手现金多少？”
- “年终奖 15 万要交多少税？”
- “打开工资计算器，选广州”

Agent 会自动提取参数、追问缺失项、按所选城市政策计算并主动提示优化空间（公积金比例提升、年终奖陷阱、未用扣除项等）。

## 扩展全国地市

在 `skills/city-salary/assets/calculator.html` 的 `CITIES` 对象中新增一行，并在 `SKILL.md` / `AGENTS.md` 参数表补一行（`node tools/check-sync.js` 会检查有没有漏）。两种城市形态各有工厂函数：

```js
// 广东型：五险基数各自独立
CITIES.城市key = CI("城市名",
  {min:医保下限, max:医保上限, comp:单位费率, emp:个人费率},
  生育参数(null 表示并入医保), {min:公积金下限, max:公积金上限},
  养老下限(默认4775), {note:"数据说明"});

// 直辖市型：五险共用一个基数区间
CITIES.城市key = CIU("城市名",
  {min:统一基数下限, max:统一基数上限},
  {medComp:医保单位费率, medEmp:医保个人费率, unempComp:失业单位, unempEmp:失业个人,
   injComp:工伤费率, hfRateMax:公积金比例上限, medFixEmp:医保个人每月固定额},
  {min:公积金下限, max:公积金上限}, {note:"数据说明"});
```

⚠️ **别把外省城市套进 `CI()`**：它的养老区间 5521~27603 是广东省级统一值，失业保险则是**法定市级口径**（下限＝本市最低工资、上限＝本市在岗职工月均×3，工厂默认 2040~本市公积金上限），两者都只适用于广东，套到外省会算错。

### 六、方法论（本批新增 / 沿用）

1. ⭐ **「灵活就业费率 = 单位费率（不含生育）+ 个人费率 ± x」是口径铁证** —— 一句话把「含不含生育」钉死，还顺带完成勾稽（无锡 7+2−1=8）。凡是官方给了灵活就业费率文件的城市，一律先找这一句。
2. ⭐ **Word97 二进制 `.doc` 纯 Python 取文**（`$env:TEMP\doc_text.py`）：olefile → FIB 偏移 0x0A bit9 选 `0Table/1Table` → 0x01A2 取 fcClx/lcbClx → Clx 里跳 `0x01` 找 `0x02` Pcdt → piece table 每 8 字节取 fc（bit30=1 为 cp1252 压缩文本，fc//2）。本批 3 份「废止/清理目录」附件全靠它验证现行性。
3. ⭐ **用「清理/废止决定」的 `.doc` 附件反向确认现行性**比页面「效力状况：有效」字段更硬（泰州市 2026 年清单不含 泰医保规〔2020〕2号 是硬证据）；但要注意**文件类别边界** —— 「锡医保服务」字头不在行政规范性文件清单内，**不等于已废止**。
4. **江苏无锡型政府 CMS 翻页规则**：`index_2.shtml`…（`index_1.shtml` 返回空，规则来自页内 JS）。
5. **JPAAS 列表面板 API**：`GET <host>/api-gateway/jpaas-publish-server/front/page/build/unit?parseType=bulidstatic&webId=…&tplSetId=…&pageType=column&tagId=…&editType=null&pageId=…`，参数从 index.html 的 `queryData="{...}"` 抄；**每次只回 15 条且无翻页参数**，count>15 时只能靠站点其它入口补齐。

### 六、方法论（本批新增 / 沿用）

1. ⭐ **「灵活就业费率 = 单位费率（不含生育）+ 个人费率 ± x」是口径铁证** —— 一句话把「含不含生育」钉死，还顺带完成勾稽（无锡 7+2−1=8）。凡是官方给了灵活就业费率文件的城市，一律先找这一句。
2. ⭐ **Word97 二进制 `.doc` 纯 Python 取文**（`$env:TEMP\doc_text.py`）：olefile → FIB 偏移 0x0A bit9 选 `0Table/1Table` → 0x01A2 取 fcClx/lcbClx → Clx 里跳 `0x01` 找 `0x02` Pcdt → piece table 每 8 字节取 fc（bit30=1 为 cp1252 压缩文本，fc//2）。本批 3 份「废止/清理目录」附件全靠它验证现行性。
3. ⭐ **用「清理/废止决定」的 `.doc` 附件反向确认现行性**比页面「效力状况：有效」字段更硬（泰州市 2026 年清单不含 泰医保规〔2020〕2号 是硬证据）；但要注意**文件类别边界** —— 「锡医保服务」字头不在行政规范性文件清单内，**不等于已废止**。
4. **江苏无锡型政府 CMS 翻页规则**：`index_2.shtml`…（`index_1.shtml` 返回空，规则来自页内 JS）。
5. **JPAAS 列表面板 API**：`GET <host>/api-gateway/jpaas-publish-server/front/page/build/unit?parseType=bulidstatic&webId=…&tplSetId=…&pageType=column&tagId=…&editType=null&pageId=…`，参数从 index.html 的 `queryData="{...}"` 抄；**每次只回 15 条且无翻页参数**，count>15 时只能靠站点其它入口补齐。
6. ⭐ **省级「各市费率分档表」在中国不存在** —— 江苏省医保局官网逐栏枚举 242 条文件 + 浙江省《医保工具书0825.pdf》「具体缴费比例由统筹地区人民政府规定」均无逐市分档表。**这条路可以从计划里删掉**，直接去市级医保局。
7. **纯扫描 PDF 是死胡同，除非走 Windows OCR**（本会话模型不支持图像输入，`inspect_image_quality` 只做元素存在性核对、**不做 OCR**）。
8. **DoH 改用 `https://1.12.12.12/dns-query` + `accept: application/dns-json`**（`223.5.5.5/resolve` 对部分域名返回 Status=0 但 Answer 为空，不可靠）。

#### 五、本批方法论（11 条）

1. ⭐⭐ **政府门户检索 API 的 `url` 字段可反查市级事业单位真实域名**（汉中公积金中心 `zfgjj.hanzhong.gov.cn` 即由此找到，DoH 猜 10 个名字全错）。前提是**省略 `catalogId` 参数**才是全站搜索；响应 `data.records[].url` 直接给出部门子站完整 URL。
2. ⭐⭐ **二进制下载必须用 `curl -o` 直写磁盘**，任何 `execFileSync(..., {encoding:'utf8'})` 都会把 PDF/PNG/JPG 的非法字节静默转成 U+FFFD。诊断信号：PIL `UnidentifiedImageError`、pypdf `incorrect startxref`、**WinRT 渲染出全白页且各页字节数完全相同**。
3. ⭐⭐ **降费/减征政策件往往比费率办法更容易拿到分解值**：衡水 2020 年减征通知里「由 7% 调至 3.5%」「生育 0.8%」直接把 7.8% 拆出来，与办法第十一条的 9.8% 交叉互证，且有四组数字同时自洽（企业 9.8%、机关 9.3%、灵活就业 9%）。
4. ⭐ **跨件算式互证比单件自校验更实用**：找出「单位合计费率条款」与「拆分费率条款」，两者相减即得单位费率。
5. ⭐⭐ **SPA 政府站点破解三步**：首页 anchor → 功能页 `<script src>` → 读功能页专属 JS 抄出 channelId 与 JSON 端点（邯郸公积金 `channelIds:232` + `350179.json?id=`，20 分钟攻克）。
6. ⭐ **TRS 系站点栏目层级**：`xxgk_gknb_list.shtml`（法定主动公开，含 `gfwj` 规范性文件）→ `common_list.shtml` → `secondLevelChannel.shtml`（二级栏）。**分页规律：`createPageHTML(…,栏目名,'shtml',总条数)` → 第 1 页用裸栏目名，第 N≥2 页用 `栏目名_N.shtml`，`_1.shtml` 反而 404**。
7. ⭐ **市公积金中心年度缴存基数通知不一定在「政策法规/中心文件」栏** —— 汉中在「新闻中心›通知公告」、渭南在「住房公积金›政策法规」、安挂在 CMS 首页，三栏都要翻。
8. ⭐ **政府门户检索 API 两种通用形态**：① 表单 GET 型 `…/jrobot/search.do?webid=1&q=<关键词>`，结果 href 是 `/jrobot/plugin/link/show.do?url=<编码后的真实URL>` 包装；② 带反爬头的 JSON 型，需 `tjmabc` + `md5(tjmabc)` 双头。
9. ⚠ **CMS 第 1 页空壳 ≠ 栏目无内容，必须翻分页**；**`index.shtml` 永久空白不代表栏目为空**（模板调 `htmlData()` 而该函数在所有外部 js 里都未定义，`index_2.shtml` 起却正常）。承德的 `/col/colXXXX/index.html` 是全通用栏目加载节点，条目由 `sessionStorage['area']` 驱动的 JS 异步加载，静态抓取永远为空。
10. ⚠ **扫描件定位条款的省法**：先 OCR 前 5 页（基金筹集通常在第二、三章），再 OCR 末 2 页查有效期与废止条款，中间页 OCR 返回空属正常。OCR 噪声靠算式自校验剔除。
11. ⚠ **部门域名缩写不可跨省套用**（湖北 `rst.`/`rsj.`、孝感 `sylbzj.`；河南 `hrss.`/`zzrs.`/`pyrs.`）；猜一个不通**不能**断定「该省不可达」。

#### 八、方法论（本批新增）

1. ⭐ **「现行有效规范性文件目录」一页证伪法**：政府门户普遍有把所有现行有效规范性文件连文号列成一张表的目录页，一次 GET 即可判断某文号是否存在且仍有效。**法理边界：只收录政府/政府办公厅文件、不含局发文件**，故只能用于证伪巴政办发〔2020〕11号、通政发〔2022〕85号这类市政府级文号，不能用于判断包医保发〔2022〕11号、锡医保发〔2021〕111号、阿医保办〔2019〕115号等局发件。
2. ⭐ **用「灵活就业生育费率」反推「企业单位生育费率」**：内医保办发〔2025〕22号 强制二者相等，故任一市公布的灵活就业生育费率在法律上即该市企业单位生育费率。这是本区目前唯一有效的数值取值线索，值得横向复制到其余 6 市盟的「政策解读/访谈」栏。
3. ⭐ **403 与 headless Chrome 软 404 都可能只是路径少写 `index.html`**（锡林郭勒亲证：不带 403/软 404，带 index.html 得 200/44601）。判 dead-end 前必须试 index.html 变体。
4. 内蒙古**没有**安徽那种动态 `.js` 友情链接文件，页脚是服务端静态 HTML 且**只给 7 个盟市**（缺通辽/巴彦淖尔/兴安盟/乌兰察布），同时混列 18 个外省省局域名，抓取须过滤。jrobot 检索 API 在三市盟全废（bynr 301 / xam 404 / huhhot 000）。
5. `web_search` 本轮两次 HTTP 429（OpenCode Zen 额度耗尽），全部成果来自直接 curl 官方站点枚举 —— **搜索引擎不可用时，门户枚举仍是主路径**。
6. ⚠ **记录库字段坑：`confirms` 不能为空**。`tools/source-records.js:37` 的 `STUB_RE = /尚未核查|占位|待核查|待查|待补充|^$|^无$|^-$/` 含 `^$`，**空 confirms 的条目会被 `isFilled` 判为未填而整体跳过**（`mismatch` 仍会被统计，所以会出现「mismatchCount 涨了但 best 没切换、urls 没涨」的怪现象）。新建记录必须写实质 `confirms`。
7. ⚠ **记录库 URL 去重**：批量清理用脚本（按 city 逐条 `Set` 去重 + 尾部空参数归一），不要手改。
